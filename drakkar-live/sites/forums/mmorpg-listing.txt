# Kingdom of Drakkar - MMORPG.com Game Listing

## Game Overview
Kingdom of Drakkar is described as "a 2D traditional fantasy MMO featuring dungeons, cities, and an extremely vast game area." The narrative centers on "an ancient evil released long ago that consumed the Earth, leaving it flooded and cultures segregated."

## Key Details
- Developer: Drakkar
- Status: Released (2001)
- Genre: MMORPG Fantasy
- PvP: No
- Business Model: Free-to-play with optional subscriptions
- Platform: PC
- Rating: 5.1/10 (63 user votes)

## Game Features
The game offers character customization through six races (City Dweller, Forest Dweller, Mountain Dweller, Outcast, Underground Dweller, Woodlands Dweller) and six professions (Fighter, Barbarian, Martial Artist, Mentalist, Healer, Thief).
