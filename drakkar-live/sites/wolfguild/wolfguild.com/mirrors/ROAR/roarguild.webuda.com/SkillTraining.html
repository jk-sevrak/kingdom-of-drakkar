You can Skill train up too 44.5% ahead without using Ugh.
You need Ugh to actually see how far ahead you have paid,
Otherwise keep paying untill trainer no longer takes coin
When you skill train for example 10% ahead, the next 10% skill will come alot faster then without skill training.

To check skill at any trainer, you can use;
*train 0 15 50
The 0 is the spot they are in on the crit list
The 15 is the number for the skill you want to check
The 50 is the amount you want to spend training.
You can pay skill using this method aslong as you are below the trainers skill limit
