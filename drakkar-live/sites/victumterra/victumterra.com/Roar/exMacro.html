*Features*
* Additional macro bars that can be placed over the game client


*How to use*
May require administrator privileges and/or started as administrator to function correctly

Check included README as well as images
Click a macro in the 'Macros' list (Will become green) then click a spot on the macro bars to place it (place them in the main windows macro bars)
Click 'Create a macro' to begin creating a macro
Right click a characters name to bring up the macro bar windows
Note: No macro bars will be visible if there are no macros set in the macro bar
