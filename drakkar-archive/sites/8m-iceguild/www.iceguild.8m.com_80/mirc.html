This is how you download Mirc and get into our chat room

First go to www.mirc.com

On left of screen click on download then download it from the closest place to where you life.

Once downloaded, install it.

Once installed, double click on the icon to start running the program.

This is how you get into our room once you've installed MIRC

Now go to file options.

Then click on any server. then click on add

Then type some type of name (ICE)

Then in irc server type 64.57.224.2

The port is 6667

Then click okay

Then click on connect to irc.

Room is #ICE
