Build 159

BUG FIXES:

A bug is fixed in this one which would sometimes cause loosing game install/update files that were being downloaded when you lost connection.
That would in turn cause having to begin the download from the start of the file when you clicked to Install/Update the game again.

NOTE: If you properly leave the SAS to exit or go to a game while a game install/update is being downloaded, then it will auto-resume when you return back to the SAS.
If you crash or loose connection then you have to manually start it up yourself.
In both cases the download will continue from where it was left in the file.
If you manually click to ABORT the download, then the local file is deleted and you'll have to start all over again.

For those of you who were unable to switch plans from the Billing room, that is now fixed.
