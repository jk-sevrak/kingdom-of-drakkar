SAS 24bit ver. 5.05 - Build 206

 

Bug fixes:


A Bug was fixed with downloading the scores file. It would cause problems when entering the pub.

Bug fixed with decoding ads. Also a workaround was added so that the SAS remembers any ads that cause it to crash so that it doesn't try to decode them again (in case the fix with decoding ads was not enough)

A bug was fixed in the ad system, where in some extreme circumstances it would crash the system (when experiencing connection slowdowns).
