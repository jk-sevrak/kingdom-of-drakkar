SAS ver. 5.20 - Build 220

 

New features:


High Speed tranfers.
The SAS can use seperate sockets when downloading files
(game updates/patches/library files/announcements etc)
This can give you transfer rates of up to 100K/sec, compared to the maximum possible rate of 10-12K before.  In addition, the newsreader also uses its own socket for connecting to the news server. This improves its performance drastically.

Users that are on a LAN, or ADSL modems or cable modems will see a major speed improvement. A slight speed improvement is also noticable on 56K modems (and I assume other modems as well)

If you have any problems with downloads after you install this patch, a small utility is provided that turns high speed transfers on and off:
http://sas.thegamers.net.other/highspd.exe

Faster game return
Changes were made to the Kernel (made available yesterday) and the Host software (made available yesterday) and to this SAS release that allow for a faster return from games.


Bug fixes:


Among other things, a bug was fixed with closing the splash screen that would cause problems on some systems
