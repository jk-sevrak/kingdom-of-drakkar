Build 155

BUG FIXES:

Fixed bug with playing MIDI's

Fixed bug with ad system

Visiting the Shopping mall now sends you to the right web site.


NEW FEATURES:

Entry added to the Red Phone context menu that directly points your browser to the SAS FAQ/version notes section

Newsreader now downloads its headers in blocks (the number of headers is user definable)
'Get Next x Headers' and 'Get All Headers' commands added to the Article Commands menu.
These 2 commands are for retrieving older headers (usually ones that expired)
Now when you visit a group the first time, the newsreader will only download the latest set of headers (current default is set to 100 headers per block)

Info area added on newsreader status bar that shows number of articles in header pane, number of unread articles and number of articles remaining on the server:
Place mouse cursor over 'i' icon for the info to show. If nothing shows when you place your cursor there, make sure you have tooltips turned on in the SAS General Options (under the Tools toolbar)
