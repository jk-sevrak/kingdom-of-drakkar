# Encrusting, Tanning & Crafting

## Encrusting

Encrusting allows players to enhance rings by coding/marking them with gems at the Nork encruster NPC. Each gem type provides a different bonus:

| Gem | Effect |
|-----|--------|
| **Lair Diamond** | EP regeneration +1 |
| **Purple with pulsating center** | EP regeneration +2 |
| **Carved Jade** | EP bonus (variable) |
| **Clear Ruby** | HP bonus (variable) |
| **Large Red Gem** | Intelligence +1 |
| **Small Red Gem** | Wisdom +1 |
| **Huge Uncut Emerald** | Willpower +1 |
| **Large Green** | Strength +1 |
| **Purple Flecked with Green** | Strength +2 |
| **Small Jade** | Agility +1 |
| **Flawless Black Pearl** | Agility +2 |
| **Large White Pearl** | Charisma +1 |
| **Large Black Pearl** | Charisma +2 |

### Encrusting Rules
- You can only encrust a ring **once**
- Encrusting quest items can ruin their usefulness - be careful!
- Embroidery from the Fun House counts as already encrusted
- The Flawless Black Pearl is also used in the Muzi quest (traded for a key on M-2), so players had to choose between encrusting and the amulet quest

## Tanning

Armor can be crafted by tanning creature hides:
- Kill the creature and obtain its hide
- Find a tanner NPC
- **Tanning command**: `# + first 3 letters of tanner name + ", tan"` (drop hide before hitting enter)
- Different creatures produce different quality armor (e.g., Red Dragon scales, Mama scales, Yeti fur)

## Notable Craftable/Tannable Items

- **Red Dragon Scales** - Standard mid-game armor from Red Dragon hides
- **Mama Scales** - High-end armor from Mama creature hides
- **Big Yeti** - Fur armor from Yeti
- **Ghost Door Cloak** - Tanned from ghost hide (N-3.5)
- **Sanquin Armor** - Beginner armor from Sanquin hides (N-3.5 area)
