# Brewing System

Kingdom of Drakkar includes an alchemy/brewing system for creating potions and items.

## Brewing Skill Levels

18 skill levels from **Untrained** to **Master Alchemist**.

## Stat Ingredients

Ingredients affect different character attributes:

| Ingredient | Stat Affected |
|-----------|--------------|
| Aconite | STR |
| Alecost | INT |
| Alpine Strawberry | WIS |
| (various others) | AGI, CON, WIL, CHA, LUK, Attacks, Speed, HP, EP |

## Ingredient Tiers

Ingredients come in quality tiers that determine potency:

1. Lesser
2. Basic
3. Simple
4. Minor
5. Common
6. Greater
7. Advanced
8. Grand
9. Titanic
10. Primal
